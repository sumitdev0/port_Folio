# Sumit Bal — Developer Portfolio 🚀

A high-performance, license-compliant personal portfolio for **Sumit Bal**, specializing in Artificial Intelligence, Machine Learning, and Full-Stack Software Engineering at Narula Institute of Technology.

---

## ✨ Features

- **100% Original & Open Source (MIT License)**: Completely clean-room engineered. No proprietary 3D models, no encrypted blobs, and zero trial plugins (`gsap-trial` removed).
- **Interactive Three.js 3D Neural Core**: Real-time WebGL interactive crystalline sphere and neural particle cloud that reacts to mouse position and inertia at 60 FPS.
- **Buttery Smooth Scroll**: Powered by [Lenis](https://github.com/darkroomengineering/lenis) (100% MIT open-source) with synchronized anchor jumps.
- **Showcase of Real Projects**: Expense Tracker, Password Manager, Python Web Automation, Smart Calculator, and Task Tracker with category filtering, highlights, and direct GitHub links.
- **Responsive & Modern Design System**: Dark cosmic palette (`#07060a`), frosted glassmorphic cards, fluid typography (`Plus Jakarta Sans` & `Space Grotesk`), custom trailing cursor, and interactive confetti triggers.
- **Vercel Ready**: Preconfigured with `vercel.json` for immediate edge deployment with zero configuration.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + TypeScript
- **Bundler**: Vite 5
- **3D Graphics**: Three.js (WebGL)
- **Smooth Scrolling**: Lenis
- **Icons**: Lucide React
- **Styling**: Vanilla Modern CSS (CSS custom properties, glassmorphism, responsive grid & flexbox)
- **Interactive Celebrations**: canvas-confetti

## 🚀 Getting Started Locally

### 1. Install Dependencies
```bash
cd sumit-portfolio
npm install
```

### 2. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
This checks all TypeScript types and outputs an optimized bundle to `dist/`.

## 🌐 Deploying to Vercel

You can deploy this website to Vercel in 2 simple ways:

### Option A: Via GitHub & Vercel Dashboard (Recommended)
1. Push your repository to GitHub.
2. In the [Vercel Dashboard](https://vercel.com/new), click **"Add New Project"** and select your repository.
3. Under **"Root Directory"**, click **Edit** and set it to:
   ```
   sumit-portfolio
   ```
4. Framework preset will automatically detect **Vite**.
5. Click **Deploy**. Your portfolio will be live with an SSL domain in under 60 seconds!

### Option B: Via Vercel CLI
```bash
cd sumit-portfolio
npx vercel
```
Follow the prompts to link and deploy directly.
